# Advanced Feature: Correlation Analysis

This module adds multi-dimensional correlation analysis.

## 1. Host → URL Correlation

Compute:
- Which hosts access which URLs
- Heatmap of host vs url_category
- Identify host specialization patterns

## 2. Host → Status Correlation

Compute:
- Error rates per host
- Redirect patterns
- Cache behavior (304)

## 3. Time → URL Correlation

Compute:
- URL category spikes over time
- Mission-related traffic patterns

## 4. Time → Status Correlation

Compute:
- Error bursts
- Traffic outages
- Cache validation cycles

## 5. Kibana Dashboards

Add:
- Correlation heatmaps
- Multi-series line charts
- Host-category matrices
